02 — AUTOMATION

GitHub Actions CI/CD

Continuous Integration and Continuous Deployment automate build, test and deployment activities.
Push Developer pushes code
→
Build Application is built
→
Test Automated tests run
→
Deploy Release to cloud
.github/workflows/ci-cd.yml 
name: DevOps CI/CD Pipeline

on:

  push:
    branches: [ main ]

  pull_request:
    branches: [ main ]


jobs:

  build-test:

    runs-on: ubuntu-latest

    steps:

      - name: Checkout Code
        uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4

        with:
          node-version: 20

      - name: Install Dependencies
        run: npm ci

      - name: Run Tests
        run: npm test

      - name: Build Application
        run: npm run build


  deploy:

    needs: build-test

    runs-on: ubuntu-latest

    steps:

      - name: Deploy
        run: echo "Deploying application..."

05 — MODERNIZATION

Monolith → Microservices

The monolithic application can be divided into independent services based on business responsibilities.

Monolithic Application

UI + Users + Orders + Database
→

Microservices

🌐 Web UI 👤 User Service 🛒 Order Service 🗄️ Independent Data

Advantages of Microservices

Independent Deployment

Each service can be released independently.

Scalability

Individual services can be scaled when required.

Fault Isolation

A failure in one service need not stop every service.

Maintainability

Smaller services are easier to understand and maintain.
